# Что было сделано в проекте

## Основная идея

В проект добавлен помощник, который:

- отвечает на вопросы по внутренней инструкции;
- показывает, из какого пункта инструкции взят ответ;
- помогает заполнить документ шаг за шагом;
- создаёт готовый файл Word (`.docx`);
- может использовать нейросеть для более понятного ответа.

## Что добавлено

### 1. Подключение API нейросети

В файл `app/knowledge.py` добавлено подключение к OpenAI-compatible API.

Сервис отправляет в нейросеть:

- вопрос пользователя;
- найденные подходящие пункты инструкции.

Если нейросеть не отвечает, проект автоматически использует локальный ответ из базы знаний.

Настройки находятся в:

- `app/knowledge.py` — логика подключения;
- `.env` — адрес API, модель и ключ;
- `config/ai.json` — настройки нейросети и будущие ограничения.

Пример настроек `.env`:

```env
AI_PROVIDER=openai
LLM_URL=https://ai.starimg.ru/v1
LLM_MODEL=название-модели
AI_API_KEY=ваш-ключ
AI_CONFIG_PATH=config/ai.json
```

Ключ API нельзя добавлять в Git или отправлять вместе с проектом.

### 2. JSON для ограничений

Добавлен файл `config/ai.json`.

В нём подготовлены настройки:

- максимальная длина запроса;
- максимальное количество токенов ответа;
- минимальная релевантность найденных пунктов;
- разрешённые темы;
- запрещённые темы;
- ограничение количества запросов.

Сейчас проект уже умеет читать:

- включена ли нейросеть;
- выбранного провайдера;
- `max_output_tokens`.

Остальные ограничения подготовлены для дальнейшего подключения.

### 3. Восстановлена структура проекта

В текущую ветку добавлены основные файлы проекта:

- `app/main.py` — API-сервер;
- `app/dialog.py` — логика диалога;
- `app/knowledge.py` — поиск и нейросеть;
- `app/render.py` — создание Word-документов;
- `app/ingest.py` — загрузка новых инструкций;
- `static/` — веб-виджет;
- `templates/` — Word-шаблоны;
- `kb/` — база знаний;
- `tests/` — тесты;
- `Dockerfile` и `docker-compose.yml` — запуск через Docker.

### 4. Добавлена документация

- `PROJECT_GUIDE.md` — подробная инструкция для коллеги;
- `API_LIMITS_MAP.md` — карта файлов, связанных с API и ограничениями;
- `WHAT_I_DID.md` — это краткое описание изменений.

## Как проверить проект

Запуск локально:

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload
```

Открыть в браузере:

- http://127.0.0.1:8000 — демо;
- http://127.0.0.1:8000/docs — документация API;
- http://127.0.0.1:8000/api/health — проверка сервера.

Запуск тестов:

```powershell
python tests\test_dialog.py
```

## Важное ограничение

В проекте используются демонстрационные данные инструкции и шаблоны документов. Перед рабочим использованием их нужно заменить на реальные документы организации.
